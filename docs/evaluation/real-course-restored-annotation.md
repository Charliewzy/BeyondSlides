# Real-course restored annotation evaluation

Date: 2026-09-03

## Scope

This evaluation exercises the restored-text annotation path on one Chinese
programming lecture:

- 2:25:12 of timestamped transcript;
- 80 slides;
- 41,313 readable characters in the restored transcript;
- 145 restored transcript windows;
- 373 assembled lecture passages.

The run resumed a previously completed and validated restoration stage. Its
24:14 wall time therefore measures preparation, slide retrieval and alignment,
model annotation, checkpoint persistence, assembly, evaluation, and rendering;
it does not measure a cold restoration run.

GLM-5 ran through an OpenAI-compatible institutional proxy with thinking
disabled for annotation. The annotation session used four concurrent windows,
a shared five-second minimum interval between request starts, five provider
retries, four tool rounds, and two final-answer repairs.

## Source-backed partition integrity

The standalone evaluator reproduced the run's automatic quality summary:

| Outcome | Candidate attempts | Rate |
| --- | ---: | ---: |
| Exact accepted | 141 | 97.2% |
| Fuzzy accepted | 4 | 2.8% |
| Rejected | 0 | 0.0% |

The four fuzzy projections changed 19 of 41,313 compared Unicode characters in
total (0.05%). Their per-window differences were 10/302 (3.31%), 7/325 (2.15%),
1/295 (0.34%), and 1/317 (0.32%), all below the strict 5% acceptance threshold.
The largest case omitted the short connective sentence “这东西肯定是成立的”
from the model's copied passage text. Projection retained that text from the
authoritative restored transcript and assigned it to the neighboring proposed
passage rather than accepting the deletion.

There were two rejected final-answer candidates, both malformed JSON rather
than passage-copy divergence: one omitted `connection_strength`, and one
wrapped the expected object in an extra `answer` field. Bounded repair accepted
the next response in both windows. The complete assembled artifact passed
standalone validation and regenerated byte-identical HTML.

This result supports the projection seam: the model can express natural text
boundaries without becoming the authority for lecture wording. It does not yet
justify changing the 5% threshold; more lectures and deliberately difficult
copy-error cases are needed.

## Provider behavior and thinking mode

The complete non-thinking run used 591,652 prompt tokens and 71,498 completion
tokens over 128 tool rounds. Fifteen transient provider failures (eight HTTP
429 and seven HTTP 503 responses) were recovered by bounded retry and request
pacing.

An earlier thinking-enabled attempt completed only 38 windows before repeated
proxy limits made it impractical. On the same first 38 windows:

| Mode | Exact | Fuzzy | Prompt tokens | Completion tokens |
| --- | ---: | ---: | ---: | ---: |
| Thinking disabled | 38 | 0 | 153,426 | 19,132 |
| Thinking enabled | 37 | 1 | 155,983 | 118,144 |

This small operational comparison strongly favors disabling thinking for this
structured copying and classification task. It is not a semantic-quality
comparison because no human labels exist for either output.

## Report comparison

The old prototype rendered raw, unpunctuated transcript text and therefore
looked like a dense ASR wall even though it preserved chronological order. The
production report renders the restored transcript as coherent, punctuated
prose. Importance remains encoded by character weight, novelty by underline
thickness, and a passage inspector exposes its score and source time without
breaking reading order.

The production report also fixes the prototype's oversized wrapping title and
removes prototype-only controls. Re-rendering requires only the validated
analysis artifact and source snapshots; no retrieval or model call is involved.

The visual design is good enough to continue product evaluation, but the scores
are not yet well calibrated:

- 297 of 373 passages (79.6%) have connection strength 4 or 5;
- 320 of 373 passages (85.8%) have importance 3 or 4;
- 369 of 373 passages (98.9%) cite at least one related slide.

These concentrations may reflect the lecture, retrieval context, rubric, or
model bias. Without human labels, tuning the prompt to make the histogram look
more balanced would be unjustified. The next evaluation should label a
stratified set of passages for boundary usefulness, novelty, importance,
connection strength, and related-slide correctness.

## Verdict

The restored-text path is ready as the first end-to-end product slice. It
solves the raw transcript readability and time-jumping problems, preserves
source provenance, survives realistic provider failures, and produces a
rebuildable continuous report. The next uncertainty is semantic calibration,
not pipeline integrity.
